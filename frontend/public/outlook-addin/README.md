# effyDOC Outlook Add-in

Transform your email workflow with real-time document tracking directly in Microsoft Outlook.

## 🚀 Features

- **Browse & Send**: Access your effyDOC documents directly from Outlook
- **Real-time Tracking**: See when recipients open, click, and read your documents
- **Live Analytics**: View engagement metrics in the Outlook sidebar
- **Preview & Edit**: Modify documents before sending
- **Smart Attachments**: Choose between trackable vs standard attachments
- **Instant Notifications**: Get alerts when recipients interact with documents

## 📥 Installation

### Option 1: Quick Install (Recommended)
1. Download the `manifest.xml` file
2. Open Outlook (Desktop or Web)
3. Go to **Get Add-ins** → **My Add-ins**
4. Click **"Add a custom add-in"** → **"Add from file"**
5. Select the downloaded `manifest.xml` file
6. Click **"Install"** and approve permissions
7. The effyDOC panel will appear in your Outlook sidebar!

### Option 2: Custom Hosting
1. Extract the complete add-in files
2. Host on your HTTPS web server
3. Update domain URLs in `manifest.xml`
4. Install via Outlook → Settings → Manage Add-ins

## 📊 How It Works

1. **Attach Documents**: Click the paperclip icon in the add-in
2. **Choose Source**: Select from your library or shared content
3. **Preview & Edit**: Review and modify documents if needed
4. **Send Trackable**: Attach as trackable document or insert link
5. **Monitor Engagement**: View real-time analytics in the Live Tracking tab

## 🔧 Troubleshooting

**Add-in not showing?**
- Ensure manifest.xml is properly formatted
- Check that your Outlook version supports add-ins
- Verify HTTPS hosting for custom installations

**Login issues?**
- Use the same credentials as your effyDOC account
- Clear browser cache and try again
- Contact support if problems persist
