🚀 Outlook Add-in Installation

Easy Installation Steps:

  1. 1
    Download the manifest file using the button above
  2. 2
    Open Outlook (Desktop or Web version)
  3. 3
    Go to Get Add-ins → My Add-ins (or Settings → Manage Add-ins for web)
  4. 4
    Click "Add from file" and select the downloaded manifest.xml
  5. 5
    Install and enjoy! The effyDOC panel will appear in your Outlook sidebar

💡 Tip: Once installed, you'll see the effyDOC panel on the right side of Outlook with three tabs: My Library, Content Hub, and Live Tracking.
