🚀 Installation Instructions

Outlook Add-in Setup:

  1. 1 Download and extract the add-in files
  2. 2 Host files on your HTTPS web server
  3. 3 Update domain URLs in manifest.xml
  4. 4 Install via Outlook Settings → Manage Add-ins

Browser Extension Setup:

  1. 1 Download and extract extension files
  2. 2 Open Chrome/Edge → Extensions
  3. 3 Enable Developer Mode
  4. 4 Click "Load unpacked" → Select folder
