# effyDOC Browser Extension

Transform your Outlook Web App with real-time document tracking directly in your browser.

## 🚀 Features

- **Seamless Integration**: Works directly with Outlook Web App
- **Real-time Tracking**: See when recipients open, click, and read your documents
- **Side Panel Interface**: Convenient sidebar that doesn't interfere with Outlook
- **Document Library**: Access your effyDOC documents directly from Outlook
- **Live Analytics**: View engagement metrics without leaving your email
- **One-Click Sharing**: Insert trackable documents with a single click

## 📥 Installation

### Chrome/Edge Installation:
1. Download the browser extension files
2. Open Chrome/Edge → Extensions (`chrome://extensions/`)
3. Enable **Developer Mode** (toggle in top right)
4. Click **"Load unpacked"**
5. Select the extracted extension folder
6. The effyDOC extension will appear in your toolbar

### Firefox Installation:
1. Download the browser extension files
2. Open Firefox → Add-ons (`about:addons`)
3. Click the gear icon → **"Install Add-on From File"**
4. Select the extension file
5. Approve the installation

## 🖥️ Usage

### First Time Setup:
1. **Open Outlook Web**: Navigate to outlook.office.com
2. **Click Extension Icon**: Look for the effyDOC icon in your browser toolbar
3. **Sign In**: Use your effyDOC account credentials
4. **Start Tracking**: The sidebar will appear in Outlook

### Daily Workflow:
1. **Compose Email**: Create a new email in Outlook Web
2. **Click effyDOC Button**: Look for the blue effyDOC button in the toolbar
3. **Browse Documents**: Select from My Library or Content Hub
4. **Insert Trackable**: Click "Insert Trackable" to add the document
5. **Send & Monitor**: Send your email and watch real-time engagement

## 🔧 Permissions Explained

The extension requests these permissions:
- **activeTab**: To interact with Outlook Web App
- **storage**: To remember your login and preferences
- **background**: For real-time notifications
- **scripting**: To inject the sidebar interface

## 🚨 Troubleshooting

### Extension Not Working?
1. **Refresh Outlook**: Reload the Outlook Web App page
2. **Check Permissions**: Ensure extension has permissions enabled
3. **Clear Cache**: Clear browser cache and cookies
4. **Reinstall**: Remove and reinstall the extension

### Can't See Sidebar?
1. **Click Extension Icon**: Click the effyDOC icon in browser toolbar
2. **Check Login**: Ensure you're signed in to effyDOC
3. **Open Outlook**: Make sure you're on outlook.office.com
4. **Allow Popups**: Ensure popups are allowed for Outlook

### Authentication Issues?
1. **Valid Account**: Ensure you have an active effyDOC account
2. **Check Credentials**: Verify your email and password
3. **Network Connection**: Check your internet connection
4. **Browser Update**: Update to the latest browser version

## 🔄 Updates

The extension automatically checks for updates. To manually update:
1. Open Extensions page in your browser
2. Click "Update" next to effyDOC extension
3. Refresh Outlook Web App

## 🔒 Privacy & Security
